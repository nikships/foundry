# Foundry Concept Art Collection

This collection extends the original Foundry forge-workcell scene into five full-frame product and marketing illustrations. Each image maintains the same near-black technical backdrop, fine ivory blueprint linework, constrained safety-orange routing lights, and deliberately quiet headline-safe space on the left. No iconography is included in this collection.

| Artwork | Scene | Suggested placement |
| --- | --- | --- |
| `foundry-intake-chamber.png` | A work item crosses from the intake rail into a calibrated factory workcell. | Landing-page hero, onboarding entry point, or prompt-to-plan story. |
| `foundry-branching-worktrees.png` | A central router distributes isolated work across four micro-workshops. | Worktree isolation, concurrent workflows, or architecture explanation. |
| `foundry-evidence-vault.png` | Evidence modules enter a radial archive through a verification corridor. | Evidence, auditability, or run-history sections. |
| `foundry-gate-tribunal.png` | Mechanical inspectors validate a work package before release. | Gates, code review, or validation sections. |
| `foundry-night-shift.png` | An autonomous workcell network continues in a calm, dark factory panorama. | Closing visual, desktop background, or product atmosphere. |

All files are 2560 × 1440 PNGs and are optimized for dark Foundry/Factory surfaces. The left third of most scenes is intentionally sparse for future headline, caption, or overlay use.
