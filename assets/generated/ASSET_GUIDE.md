# Foundry Generated Asset Set

This asset set translates the Foundry repository’s product language—repeatable workflows, evidence, gates, and workcells—into the active Factory design system: near-black technical surfaces, ivory drafting lines, restrained safety orange, compact industrial geometry, and minimal status color.

| Asset | Dimensions | Intended use |
| --- | ---: | --- |
| `foundry-forge-workcell-hero.png` | 2560 × 1440 | Product website or README hero. The left third is intentionally quiet for headline copy. |
| `foundry-orchestrator-agent.png` | 1920 × 1920 | New agent avatar for an Orchestrator, coordinator, or pipeline-runner role. |
| `foundry-run-cleared.png` | 1920 × 1920 | Run-success, gate-accepted, or evidence-complete empty state. |
| `foundry-pipeline-sigil.png` | 1920 × 1920 | Pipeline, workflow, worktree, or orchestration icon for a dark panel. |
| `foundry-evidence-gate.png` | 1920 × 1920 | Verification, proof, gate, or acceptance icon for a dark panel. |

All icons are intentionally rendered against the Factory base black (`#020202`) rather than with alpha transparency, ensuring they remain clean and artifact-free in the repository’s intended dark interface. The orange accent aligns with Factory’s `#EE6018` signal color; ivory linework aligns to the system’s light text treatment.
