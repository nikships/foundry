# Plan: Inspector Lane Density Control

## 1. Goal
Add a draggable scale (range slider) to the Inspector footer that controls the width of phase lanes (TranscriptLanes). The user can adjust density from wide (e.g., 1-2 lanes filling the screen) to compact (up to 6 lanes visible).

## 2. Approach
- **State**: Add a `laneCount` state (defaulting to 3) in `InspectorScreen.tsx`. Persist it to `sessionStorage` so navigating to other screens and back retains the user's preference without needing main-process persistence.
- **UI Element**: Add a standard `<input type="range" min="1" max="6" />` to the `.inspectorFooter`. Label it "Lanes" and style it natively with an accent color.
- **CSS Logic**: In `InspectorScreen.module.css`, change `.inspectorGrid` to accept a `--lane-count` variable. Calculate the width of each lane inside `.inspectorGrid > *` dynamically using `calc((100% - (var(--s3) * (var(--lane-count) - 1))) / var(--lane-count))`.

## 3. Exact File Changes

### `apps/desktop/src/renderer/screens/InspectorScreen.module.css`
1. Update `.inspectorGrid` to set a default `--lane-count`:
   ```css
   .inspectorGrid {
     ...
     --lane-count: 3;
   }
   ```
2. Update `.inspectorGrid > *` to use the variable for dynamic widths:
   ```css
   .inspectorGrid > * {
     flex: 1 0 calc((100% - (var(--s3) * (var(--lane-count) - 1))) / var(--lane-count));
     min-width: min(100%, calc((100% - (var(--s3) * (var(--lane-count) - 1))) / var(--lane-count)));
     max-width: 100%;
     height: 100%;
     min-height: 0;
     scroll-snap-align: start;
   }
   ```
3. Add new classes for the density slider layout in the footer:
   ```css
   .inspectorDensity {
     margin-left: auto;
     display: flex;
     align-items: center;
     gap: var(--s2);
   }
   .densityLabel {
     font-family: var(--font-mono);
     font-size: 10px;
     color: var(--text-faint);
     letter-spacing: 0.02em;
     text-transform: uppercase;
   }
   .densitySlider {
     width: 100px;
     accent-color: var(--accent);
     cursor: pointer;
   }
   ```

### `apps/desktop/src/renderer/screens/InspectorScreen.tsx`
1. **State Addition**: 
   Near the top of `InspectorScreen`'s body, add `laneCount` and persist it:
   ```tsx
   const [laneCount, setLaneCount] = useState<number>(() => {
     const saved = sessionStorage.getItem('inspectorLaneCount');
     return saved ? parseInt(saved, 10) : 3;
   });

   useEffect(() => {
     sessionStorage.setItem('inspectorLaneCount', laneCount.toString());
   }, [laneCount]);
   ```
2. **Apply Variable**: 
   Find `<div className={styles.inspectorGrid}>` and change it to:
   ```tsx
   <div className={styles.inspectorGrid} style={{ '--lane-count': laneCount } as React.CSSProperties}>
   ```
3. **Add to Footers**: 
   In both `!project` (empty state) and the main return's `<footer className={styles.inspectorFooter}>`, append the density control next to `.inspectorFooterHint`:
   ```tsx
   <div className={styles.inspectorDensity}>
     <span className={styles.densityLabel}>Lanes</span>
     <input
       type="range"
       min="1"
       max="6"
       step="1"
       value={laneCount}
       onChange={(e) => setLaneCount(parseInt(e.target.value, 10))}
       className={styles.densitySlider}
       disabled={!project} /* Disable only in the no-project empty state */
       aria-label="Adjust visible lanes density"
     />
   </div>
   ```

## 4. Verification Steps
1. Run `npm run check` in `apps/desktop` to ensure TypeScript, ESLint, style checks (`check:css`), and Vite builds pass.
2. Open the app and navigate to the Inspector.
3. Observe the new "Lanes" slider in the footer aligned to the right.
4. Drag the slider to `1`, confirm only one lane fills the viewport. Drag to `6` and confirm lanes shrink to fit 6 in the viewport.
5. Verify scroll-snap and horizontal scrolling continue to work for overflowing lanes.
6. Refresh the page or navigate away and back, and verify the chosen lane count persists for the session.
